# 🚬 Smoking & Health Risk Analysis Dashboard

An interactive **Power BI dashboard** that analyzes the impact of smoking on patient health using patient demographics, BMI, blood pressure, cholesterol, and organ health data. The dashboard provides interactive visualizations and insights to support data-driven healthcare decisions.

## 🛠️ Technologies Used
- Power BI
- DAX
- Power Query
- Microsoft Excel
